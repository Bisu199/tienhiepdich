# tienhiepdich

hướng dẫn:
- ae tải file rar trong release về
- hoặc có thể tự tải source cũng đc 
- giải nén ra
- mở chrome lên, vào extension manager, chọn load unpacked (trên cùng góc trái)
- dẫn vào thư mục vừa giải nén (tới khi thấy folder locale thì bấm chọn folder)
- nó sẽ tự add vào chrome
- mở extension vừa cài lên và chọn setting
- trong đây các bạn chọn model phù hợp (cá nhân mình thấy gemini là free và nhanh nhất), add api key vào (cách lấy apikey các bạn google giúp mình nha, cũng dài dòng nhiều step nhưng dễ lắm)
- xong bấm save lại là đc

  
tiếp theo là đọc truyện
- search tên truyện của các bạn = tiếng việt + tên tác giả, nhờ google AI tìm tên truyện tiếng trung
- copy tên truyện tiếng trung xong paste vào google search xong gõ thêm nguồn

  
ví dụ: mình đang đọc bộ đã nói trải nghiệm nhân sinh, tiên tử sao thành sự thật. mình dùng AI dịch ra thì ra đc cụm từ: 說好體驗人生，仙子你怎麼成真了

mình sẽ rà từ từ :
- 說好體驗人生，仙子你怎麼成真了69shuba
- 說好體驗人生，仙子你怎麼成真了novel543
- 說好體驗人生，仙子你怎麼成真了ttkan

và có thể thêm số chapter vào (ví dụ các đạo hữu đọc tới chap 255 thì mất, thì giờ search tên tiếng trung + 256 cũng có khả năng tìm ra)
ngoài ra đạo hữu nào có nguồn text trung khác thì share lên cho ae xài chung với nhé

tiếp theo là khi vào được web rồi thì các đạo hữu bấm extension lên và bấm translate, chờ 1-2 phút là xong. enjoy
